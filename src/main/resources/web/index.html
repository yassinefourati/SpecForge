      Join tables

      These tables only link two others, so they are mapped as many-to-many relations. Generate one as an entity of its own when it should have its own endpoints.

        Endpoints

        Use-case controllers

        Combine operations of several tables in one controller: create or update a parent with its children in one transaction, read a parent with its children, list a parent's children, or move a table's own operations here.
